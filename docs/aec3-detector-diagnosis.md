# AEC3 近端检测与残余抑制消融（2026-10-21）

状态：离线诊断完成；组合候选可重复改善近端保留，但弱双讲仍未达门槛，且 RNNoise 后的路径变化回声指标出现退化。候选不接入 RTC。

## 诊断设计

复用相同的电平规范化语音和模拟回声，每个场景、模式均为全新 AEC 实例，关闭 RNNoise 做第一轮归因。除官方默认外，比较：

- `nearend-mask`：只放宽已进入近端保护状态后的高频掩蔽参数。
- `bounded-residual`：近端检测只使用有界残余回声谱。
- `sensitive`：ENR 阈值 0.75、SNR 阈值 10、触发 6 块、保持 100 块；掩蔽参数仍为默认。
- `sensitive-mask`：组合敏感检测与 nearend-mask。

没有修改线性滤波、延迟估计、输入增益或质量门槛。入口只存在于离线 `--compare`。
首段报告：`.local/aec-comparison-1792564640078/results.json`；后段报告：`.local/aec-comparison-1792564671673/results.json`。
后段使用原录音 25–55 秒，独立重新计算固定增益；虽未用于本轮参数选择，但与前段来自同一说话人和同一次录音，不能称独立语料库。

## 消融结论

- bounded-residual 没有改善近端单讲或模拟耳机，并使首段双讲 SNR 5.46 → 5.32 dB、弱双讲 4.59 → 4.26 dB。残余谱是否有界不是当前主要改善方向。
- sensitive 单独只有小幅改善，说明检测覆盖不足存在，但不是唯一瓶颈。
- nearend-mask 单独改善更明显，说明进入保护状态后默认后级抑制仍是更大的损伤来源。
- sensitive-mask 在两段素材均改善最大，说明两个因素叠加；这仍是由输出变化推断的消融证据，不是逐帧内部状态计数。

| 无 RNNoise | 首段默认 | 首段组合 | 后段默认 | 后段组合 |

两段的远端单讲和路径变化纯回声指标在关闭 RNNoise 时基本不变。组合候选仍未让弱双讲 SNR 达到既有 8 dB 门槛。

## 完整链路复核

随后运行默认与组合候选的 AEC3 → RNNoise 全链路。
首段报告：`.local/aec-comparison-1792564698538/results.json`；后段报告：`.local/aec-comparison-1792564722648/results.json`。

- 首段双讲 SNR 5.50 → 6.61 dB，弱双讲 4.63 → 5.60 dB。
- 后段双讲 SNR 7.49 → 8.47 dB，弱双讲 5.98 → 7.39 dB。
- 固定路径纯回声衰减基本不变；路径变化后的 AEC3 + RNNoise 衰减首段 68.53 → 68.21 dB，后段 63.23 → 61.01 dB。数值仍高，但后段下降约 2.22 dB，禁止表述为无回声代价。
- 所有输出保护计数为 0；候选每帧 P95 与默认同量级，单次运行不能证明性能相同。

## 当前判断

诊断支持“近端检测覆盖不足 + 进入保护后仍压得偏强”，其中后级掩蔽影响更大。组合候选方向合理，但尚不具备推广条件：弱双讲失败，完整链路路径变化指标有退化，同一录音重复使用容易过拟合，而且没有逐帧状态/残余功率/增益统计。

下一步应实现只在诊断构建启用的内部统计钩子，记录 dominant-nearend 占比、残余回声与近端功率比、低频增益分位数，并在未见输入上核对；不再继续盲调阈值。
