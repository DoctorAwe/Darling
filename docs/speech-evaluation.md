# 离线语音文件评测

## 当前状态

已实现 WAV 输入、默认 AEC3 同输入基线、输入保护和可追溯报告。尚未获得来源/授权明确的两段真实语音；当前自动测试用生成噪声验证工具，不能当作语音音质验收。

本入口不打开音频设备、不录音、不上传、不导出处理后音频，不修改默认客户端。依赖目录内附带的 WAV 未因文件名为 near/far 就被认定为干净且独立的语音素材。

## 输入和执行

需要两位不同说话人的独立干净录音，各至少 40 秒，标准 RIFF WAV、48 kHz、单声道、16-bit PCM。记录来源、使用许可、说话人是否独立。不要将同一段录音复制为两路。

```powershell
./scripts/evaluate-speech.ps1 -FarWav 'D:\Audio\far.wav' -NearWav 'D:\Audio\near.wav' -SourceNote '素材来源、许可及两路说话人说明'
```

需先构建实验目标 `aec3-evaluation`。底层入口为 `aec3-evaluation.exe --speech-wav <far.wav> <near.wav>`。

附加 `-ComparePaths` 可对照变化路径、固定 40 ms/0.6、固定 160 ms/0.35，底层入口为 `--speech-paths`。每场景独立创建处理器；全部达到原门槛才返回 0。额外窗口电平仅用于定位，不放宽门槛、不从输出能量扣除控制底噪。

`-DiagnosticGainDb 12` 或 `24` 会自动运行三路径诊断；底层为 `--speech-gain-12/24`。仅对内存中前 40 秒的两路输入同时施加固定增益，近端独立基线亦使用相同增益。不是 AGC、不改变录音文件、不回缩输出、不降低质量标准。输入或混音将削波时返回 65，不限幅继续。报告记录增益；不能将加增益的结果当作原始电平验收。

`-LowExcitation` / `--speech-low-excitation` 为独立候选：原始电平、三路径，仅将 `render_levels.poor_excitation_render_limit` 从 150 改为 `150 / 10^(12/20)`（约 37.6783），默认下采样因子 4 保持不变，不改 ds8 阈值或抑制参数。此值对应前一轮 +12 dB 的激励判据，但不等价于放大整条处理链。不能与增益选项同时使用。近端独立控制仍为 Default，便于与原始基线比较；该控制没有远端信号。候选尚未通过完整生产验收，不默认启用。

只用两路文件的前 40 秒，不循环、不重采样、不归一化。近端只在 10–20 秒注入（使用近端文件对应时间段），远端全程播放；回声主路径在第 25 秒由 40 ms/0.6 变为 160 ms/0.35，另含延后 15 ms、增益 0.12 的反射。仍为**语音驱动的合成回声**，不是实测房间声学。

拒绝错误格式、截断/重复数据块、超过 64 MiB 的文件、不足 40 秒、前 40 秒逐样本相同的两路输入、评测窗口 RMS 低于 −60 dBFS，以及混合信号削波。内容是否真为语音、是否为不同说话人必须由素材提供者确认，脚本不自动证明；能量检查也不是 VAD。

## 指标与报告

- 双讲 12–19 秒与独立处理的近端基线比较：相关性 ≥0.85，投影增益 ±3 dB 内，基线 SNR ≥8 dB。不使用拟合增益或搜索到的时移参与判定。
- 回声单独存在时，5–9 秒和 35–39 秒衰减均 ≥15 dB。
- 仅 Default profile；原合成测试门槛未变。基线也经过 AEC3，因此本测试不能单独证明对原始语音完全无损；后续仍需原始语音保真、听感和设备声学验收。
- 报告独立保存于 `.local/aec3-speech/<随机ID>/report.json`，包含素材路径、SHA-256、来源说明、可执行文件 SHA-256、输出和退出码。运行前后检查素材哈希，变化则判输入无效；来源说明是声明，不是授权验证。
- 退出码 0：这对文件在该场景达到指标；11：质量不通过；65：输入无效。其他执行错误也不视为通过。缺失路径等启动前错误会直接报错，不一定生成报告。

## 回归测试

`-NegativeNearendMask` / `--speech-negative-mask` 对照 Default 与已有 DiagnosticNearendMask（只放宽近端状态的 mask_hf，不叠加低激励改动）。同样运行四种负例，并输出 12–19 秒的 usable、dominant 块计数和频点平均幅度增益。每窗 1750 个内部块；平均频点增益不是输出 RMS 比，不能直接换算人声音量损失。脚本拒绝与路径、增益或 LowExcitation 开关组合。

`-NegativeControls` / `--speech-negative` 独立运行 Default 与低激励候选的四种无回声场景，不能混用增益/路径/候选开关：近端独讲、耳机无回声（远端录音仅作为参考）、低电平无关噪声参考（固定种子，预期 RMS −60 dBFS）、静音麦克风+远端参考。各运行 40 秒，近端在 10–20 秒注入；与独立 Default 近端控制比较 12–19 秒，沿用相关性 ≥0.85、增益 ±3 dB、SNR ≥8 dB；另在静音麦克风 5–40 秒或其他场景 25–40 秒要求输出 RMS ≤−70 dBFS。无回声时不计算回声衰减。静音场景没有保真指标，−300 dBFS 是数值下限。

两个 profile 全部通过才退出 0，质量失败返回 11。当前使用合成数字无回声，不证明真实耳机绝不漏音，也没有验证耳机路由选择是否正确。候选延迟赢家/有效估计计数用于风险定位，不把赢家数量等同于已接受的延迟。

`speech-wav-test` 覆盖 PCM 解码、奇数块补齐、截断、错误格式及重复数据块；`node --test scripts/speech-evaluation.test.mjs` 用临时生成噪声检验 CLI、无效输入、削波和报告/退出码传播。临时 WAV 测完删除，生成的审计报告保留，其素材路径之后不再存在。
