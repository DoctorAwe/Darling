# 官方 AEC3 线性输出诊断（2026-10-21）

使用官方 `GetLinearAecOutput` 导出 16 kHz 低频带，未改第三方源码。
显式离线参数 `--trace-linear` 同时打开 APM 输出缓冲与 AEC3 导出配置。
最终 48 kHz 输出另经 AudioBuffer 分频，取低频带；与同模式近端单讲线性输出对齐比较。
RNNoise 关闭，以排除后续独立降噪的影响。

复现：构建 `darling_aec_chain_test`，再运行 `node scripts/diagnose-aec3-linear.mjs`。
输入复用 `.local/aec-comparison-1792564180176` 的原样规范化 float PCM，不重新放大或改变参考。
报告：`.local/aec3-linear-1792564407588/report.json`。

8 组执行完成，输出保护均为 0。每组导出诊断后的全频输出 SHA256 与前轮未开启导出的输出一致，确认诊断未改变原有输出。

## 默认配置结果

| 场景 | 线性输出相关性 | 线性投影增益 dB | 最终低频带相关性 | 最终投影增益 dB |
|---|---:|---:|---:|---:|
| 近端单讲 | 1.000 | 0.000 | 0.984 | −0.189 |
| 模拟耳机无回声 | 0.983 | −0.353 | 0.875 | −2.604 |
| 双讲 | 0.979 | −0.275 | 0.845 | −3.329 |
| 弱近端双讲 | 0.970 | −0.280 | 0.808 | −4.177 |

双讲 SNR 从线性输出 13.816 dB 到最终低频带 5.410 dB；弱双讲从 12.283 到 4.574 dB。
近端单讲线性输出与自身比较的约 323 dB SNR 是数值下限现象，不是物理性能。

## 候选复核

`aec3-nearend-mask` 的线性输出指标与默认完全相同；最终双讲增益 −2.782 dB、弱双讲 −3.518 dB，仍有损伤。
这符合候选只改后级掩蔽配置、没有改变线性滤波的预期。

## 结论边界

在本组录音与模拟路径中，线性消除之后的处理是剩余近端损伤的重要来源，暂不应优先重写线性滤波器。
但这不等于已经证明某个抑制公式错误，也不能区分近端检测、残余功率估计、抑制增益及滤波重组各自贡献。
最终输出再分频本身也引入变化，近端单讲控制已显示约 −0.189 dB 与相关性 0.984；不能把所有前后差值都归于抑制器。
只评估 16 kHz 低频带，非 48 kHz 全频结论。相对近端线性基线不是相对原始 WAV 的绝对保真度。未做独立语料、实机或主观听感测试。

下一步针对近端检测状态、残余回声功率和实际抑制增益增加统计，区分“没有进入保护状态”和“进入保护后仍压得过强”。不移除残余抑制，不直接以线性输出替代生产音频。
本轮未改变 RTC 默认或候选参数、稳定客户端、服务器及源录音。
