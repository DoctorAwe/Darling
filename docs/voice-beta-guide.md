# Darling 双机语音测试版

适用 Windows x64。先完整解压，不要直接在压缩包内运行。双击 Darling.exe，无需安装 Node 或 SDK。

两个人分别使用 DVa 和 Mercy 包，不要同时使用同一账号。账号配置已随各自的包附带，启动自动登录；同账号的新登录会替换旧客户端。包内含密码，请只私下发给对应测试者，不要公开上传。

## 开始通话

1. 两端启动后自动登录，确认对方在线。
2. 一方点击“发起语音 · 测试版”，另一方点击“接听 · 开启麦克风”，无需手动配置设备。每次通话自动读取 Windows 系统默认输入和输出；Windows 识别为耳机/耳麦的输出强制关闭 AEC，其他输出开启 AEC，降噪始终默认开启。
3. 连接成功后显示通话时长和对方接收电平。任意一方点击“结束连接”即停止音频；不会自动接听或重拨。

来电与拨号提示音通过 Windows 默认输出播放，进入连接阶段、拒绝或挂断后停止，不混入网络音频流。设备面板保留独立诊断功能，不影响实际通话的默认配置。

15 秒 RTC 设备测试是独立的本机测试，播放的是 1200Hz 测试音；不需要先完成它才能通话。真实双机通话不会生成测试音。

## 本版边界

- 语音固定走公网 TURN 中继（支持 UDP/TCP 候选），暂不提供自动直连切换。
- 呼叫/建连超时 30 秒；通话上限 30 分钟，到时可重新呼叫。无静音按钮，需停止采集时请挂断。
- 耳机分类依据 Windows 驱动的设备类型，不根据名称猜测；驱动标记为未知、线路或扬声器的设备不能自动确定其末端是否为耳机。AGC/高通关闭，RAW 及最终音质、CPU 占用尚未验收。
- 使用过程中暂不支持热切换音频设备，拔插或设备异常请挂断、重新检测后再拨打。
- 文字聊天可用；文件、截图、远程桌面尚未实现。
- 未做代码签名。若系统提示，先核对来源；不要关闭杀毒或防火墙。应用运行需要访问麦克风及网络。

请反馈：两端设备名称/耳机类型、是否双向有声、断续/回声/爆音情况、挂断后是否停止。无需发送密码或录音。
