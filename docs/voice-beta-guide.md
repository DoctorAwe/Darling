# Darling 双机语音测试版

当前版本：0.9.0-beta.9。主线回声消除使用官方 WebRTC AEC3，之后串联 RNNoise；保留双向独立静音控制且无应用层通话时长上限。
请两端都退出旧版、完整解压新版到独立目录后运行，不覆盖正在运行的客户端。
beta.5 不建议继续用于语音。新版已通过离线回归，但仍需低音量实机验证。

适用 Windows x64。先完整解压，不要直接在压缩包内运行。双击 Darling.exe，无需安装 Node 或 SDK。

两个人分别使用 DVa 和 Mercy 包，不要同时使用同一账号。账号配置已随各自的包附带，启动自动登录；同账号的新登录会替换旧客户端。包内含密码，请只私下发给对应测试者，不要公开上传。

## 开始通话

1. 两端启动后自动登录，确认对方在线。
2. 一方点击“发起语音 · 测试版”，另一方点击“接听 · 开启麦克风”，无需手动配置设备。每次通话自动读取 Windows 系统默认输入和输出；耳机与扬声器均启用 WebRTC AEC3 回声消除，RNNoise 降噪始终默认开启。
3. 连接成功后显示通话时长和对方接收电平。任意一方点击“结束连接”即停止音频；不会自动接听或重拨。

来电与拨号提示音通过 Windows 默认输出播放，进入连接阶段、拒绝或挂断后停止，不混入网络音频流。设备面板保留独立诊断功能，不影响实际通话的默认配置。

15 秒 RTC 设备测试是独立的本机测试，播放的是 1200Hz 测试音；不需要先完成它才能通话。真实双机通话不会生成测试音。

## 本版边界

- 主线处理链为官方 WebRTC AEC3（含残余回声抑制）→ 本地 RNNoise v0.2 官方模型 → Opus。WebRTC NS、AGC 和高通关闭，避免与 RNNoise 重复处理。PBFDAF 仅保留为开发对照与显式回退，不再是发布默认值。耳机与扬声器均启用 AEC；真实双机听感和长期性能仍需继续验收。

- 语音固定走公网 TURN 中继（支持 UDP/TCP 候选），暂不提供自动直连切换。
- 呼叫/建连超时仍为 30 秒；已接通的通话不再设置应用层时长上限。
- 通话中可以分别切换麦克风静音和对方声音静音，再次点击恢复。静音麦克风发送静音音轨，但保持设备及回声处理运行；需要完全停止采集时请挂断。
- 两端均须使用本版客户端，以兼容新版服务端无通话截止时间的状态。
- 耳机分类依据 Windows 驱动的设备类型，不根据名称猜测；驱动标记为未知、线路或扬声器的设备不能自动确定其末端是否为耳机。AGC/高通关闭，RAW 及最终音质、CPU 占用尚未验收。
- 使用过程中暂不支持热切换音频设备，拔插或设备异常请挂断、重新检测后再拨打。
- 文字、文件、截图和远程桌面均可用。远程桌面使用原生 Windows Graphics Capture，不捕获被控端系统光标；控制端显示即时本地光标。连接优先直连，失败时自动使用 TURN 中继。
- 远程桌面中的语音只传输双方系统默认麦克风，不共享被控端系统播放声音；远程状态栏可关闭语音或撤销操作权限。
- 本版原生桌面轨仍使用 WebRTC 内置软件视频编码器，尚未接入 NVENC；请重点反馈远程时 CPU 占用、延迟和画质。
- 未做代码签名。若系统提示，先核对来源；不要关闭杀毒或防火墙。应用运行需要访问麦克风及网络。

请反馈：两端设备名称/耳机类型、是否双向有声、断续/回声/爆音情况、挂断后是否停止。无需发送密码或录音。
