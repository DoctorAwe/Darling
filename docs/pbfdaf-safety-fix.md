# PBFDAF 异常增益与参考欠载修复

日期：2026-10-20。版本 beta.6，原生 0.4.1-aec-safety，算法 darling-pbfdaf-v2。
保持耳机启用 AEC、RNNoise 默认开启；没有切回 AEC3 或新增 SDK。

## 缺陷与修复

- beta.5 在没有声学回声、近端信号峰值 0.15、远端参考从弱变强的
  确定性离线测试中，AEC 峰值曾达到 58.161057。原始弱参考步长缺少
  足够正则化，第一次前台滤波器提升绕过了效果验证。
- 现在低于 −60 dBFS 的当前参考块不更新滤波器；按宽带能量正则化频点，
  前后台切换一律要求连续两个有效窗口的改善，取消首次无条件提升。
  对后台系数能量设界，并检查前台及 RES 输出是否出现非有限值、异常增益或超满幅。
  触发时丢弃异常模型并旁路该块，不把失控输出送入 RNNoise。
- 对已学到却失效的路径：连续两个统计窗口证明前台比原始采集还差时，
  清除失效模型，避免在耳机/路径消失后不断减入不存在的“回声”。
- 单帧参考欠载不再重置整个 AEC，而是插入零参考推进历史、冻结更新并旁路该块。
  SPSC 队列给参考块附生产序号，迟到块丢弃，不挪到下一采集时刻使用。
  连续三帧缺参考才重建时间基准，避免相位永久错位；溢出/格式变化仍重新对齐。
  这不是完整硬件时间戳或声卡漂移补偿。
- RNNoise/重采样之后增加末级有限值和满幅保护，异常全块等比例缩小或静音，
  不使用逐样本硬削波。正常块不改变增益。统计新增 safetyEvents / outputProtection。

## 回归结果（无麦克风、无扬声器、无上传）

- 三档弱参考→强参考、无回声负例：输出峰值 0.150000，整体增益 0.000 dB。
- 真实 WebRTC APM 钩子复现：RNNoise 关闭峰值 0.150000，开启峰值 0.008245；
  两者 outputProtection=0，证明不是靠末级限幅掩盖失控。
  此处近端用独立随机信号，RNNoise 的低输出不是人声保真指标。
- 真实 APM 固定 100 ms 合成回声：稳定场景尾段衰减 95.557 dB；
  每 500 ms 出现一次 10 ms 迟到参考时 16.882 dB，13 次缺参考仅有启动时一次重置。
  理想纯延迟结果不能替代真实房间或扬声器验收。
- 双讲、已学路径消失、FFT、延迟、RES、近端单讲、重置、队列并发及迟到丢弃通过。
- 16/32/48 kHz、同实例格式切换、RNNoise 开/关回归通过。

实机的原始日志未取得，所以不能断言上述缺陷是用户通话故障的唯一原因。
仍待验证真实双机、音箱非线性、长混响和时钟漂移。禁止将“离线通过”表述为音质验收。
